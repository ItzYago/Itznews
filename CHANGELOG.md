# Changelog — ItzNews

Todas as mudanças relevantes do **ItzNews** serão documentadas neste arquivo.

O projeto segue versionamento semântico: `MAJOR.MINOR.PATCH`.

---

## [0.1.0] — Initial Setup

### Added

* Criação inicial do projeto **ItzNews**.
* Configuração inicial do Django.
* Estrutura base da aplicação.
* Configuração inicial do banco de dados.
* Primeira página do projeto.
* Configuração inicial de templates.
* Configuração inicial de arquivos estáticos.

---

## [0.2.0] — News System

### Added

* Criação do modelo de notícias.
* Cadastro de título, conteúdo e data de publicação.
* Listagem de notícias.
* Página individual para cada notícia.
* Estrutura inicial para categorias.

---

## [0.3.0] — Categories

### Added

* Sistema de categorias.
* Associação de notícias às categorias.
* Página de notícias por categoria.
* Navegação entre categorias.

---

## [0.4.0] — Admin Panel

### Added

* Configuração do Django Admin.
* Gerenciamento de notícias pelo painel administrativo.
* Gerenciamento de categorias.
* Gerenciamento de autores.
* Organização dos campos no painel administrativo.

---

## [0.5.0] — Users

### Added

* Sistema de usuários.
* Login.
* Logout.
* Controle de permissões.
* Associação de notícias aos autores.

---

## [0.6.0] — Media

### Added

* Upload de imagens para notícias.
* Imagem de destaque.
* Configuração de arquivos de mídia.
* Exibição de imagens nas páginas de notícias.

---

## [0.7.0] — Search

### Added

* Sistema de busca.
* Pesquisa por título de notícia.
* Filtros básicos por categoria.
* Página de resultados.

---

## [0.8.0] — Comments

### Added

* Sistema de comentários.
* Associação de comentários às notícias.
* Identificação do usuário responsável pelo comentário.
* Moderação básica de comentários.

---

## [0.9.0] — API

### Added

* Criação da API do ItzNews.
* Endpoints para notícias.
* Endpoints para categorias.
* Serialização dos dados.
* Estrutura inicial para consumo externo da API.

---

## [0.10.0] — Improvements

### Improved

* Melhorias na organização do projeto.
* Melhorias no sistema de templates.
* Melhorias no painel administrativo.
* Otimização das consultas ao banco de dados.
* Melhorias de responsividade.
* Correções gerais.

---

## [1.0.0] — First Stable Release

### Added

* Sistema completo de notícias.
* Categorias.
* Autores.
* Usuários e autenticação.
* Comentários.
* Busca.
* Upload de imagens.
* Painel administrativo.
* API.
* Interface responsiva.

### Improved

* Segurança da aplicação.
* Performance.
* Organização do código.
* Experiência de navegação.

### Status

**Stable Release**
