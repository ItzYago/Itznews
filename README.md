# ItzNews

> Portal de notícias desenvolvido com Python e Django.

O **ItzNews** é uma aplicação web para publicação e gerenciamento de notícias, com suporte a categorias, usuários, autenticação e gerenciamento de conteúdo.

## Tecnologias

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Django REST Framework

## Funcionalidades

* Publicação e gerenciamento de notícias
* Categorias
* Autenticação de usuários
* Sistema de autores
* Upload de imagens
* Busca de notícias
* Comentários
* Painel administrativo
* API REST
