## 📌 Sobre o Projeto

O **ItzNews** é uma plataforma moderna projetada para simplificar a publicação e a leitura de conteúdos jornalísticos. O objetivo do portal é centralizar a informação de forma organizada, oferecendo navegabilidade fluida para os leitores e ferramentas eficientes para os editores.

A plataforma elimina barreiras de usabilidade, entregando um ambiente limpo para leitura e uma estrutura sólida para gerenciamento de matérias e autores.

## 💡 Por que o ItzNews?

Em um cenário saturado de excesso de dados e interfaces poluídas, o **ItzNews** surge para resolver problemas estruturais no consumo de informação digital:

* 🎯 **Foco na Leitura:** Layout intuitivo que prioriza o texto e a mídia sem distrações visuais.
* ⚡ **Acesso Rápido:** Categorização clara e busca eficiente para encontrar matérias em segundos.
* 🛡️ **Curadoria Editorial:** Estrutura organizada para múltiplos autores e editores publicarem com controle.
* 💬 **Comunidade Ativa:** Espaço para debates construtivos através do sistema de comentários.

---

## 🎯 Objetivos

* 🌐 **Acesso Centralizado:** Oferecer um portal intuitivo para leitura rápida e navegação estruturada.
* ✍️ **Gestão Editorial:** Prover um fluxo simplificado para criação, edição e publicação de matérias.
* 💬 **Engajamento dos Leitores:** Estimular o debate e a interatividade por meio de comentários e filtros por temas de interesse.

## 🔄 Fluxo de Uso

1. **Descoberta:** O leitor explora as notícias de capa ou utiliza as categorias para filtrar tópicos de seu interesse.
2. **Leitura:** Acesso à matéria completa com suporte visual e identificação do autor.
3. **Engajamento:** O leitor participa do debate enviando comentários na publicação.
4. **Administração:** Autores e administradores gerenciam a publicação e atualização de novos artigos.
